# Repository guidelines

- This repository belongs to **This Week In Newsletters**.
- Keep `templates/newsletter-template.md` empty. New drafts must be empty files; copy reviewed Formatted output from `gen-newsletter-obsidian` into them. Maintain the content template only in the generator's `output/templates/formatted_template.md`.
- Commit directly to `main` by default; create a pull request only when the user explicitly requests one.
